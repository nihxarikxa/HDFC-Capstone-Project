This repository contains two core components of my capstone solution for HDFC Bank’s Digital KYC problem. 
The written report analyzes the root causes of customer drop-offs in the existing digital KYC journey and proposes the “Digital KYC Assist Framework” as a practical, scalable, and customer-centric solution. 
The Python notebook complements this by validating the findings using real dataset inputs; it highlights stage-wise failure patterns, quantifies their impact on customer onboarding, and demonstrates how the proposed improvements can significantly reduce drop-offs and increase overall conversion rates. Together, the report and notebook form a complete solution that is both conceptually strong and supported by data-driven validation.
